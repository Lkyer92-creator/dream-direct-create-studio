# DDC Studio — Dream Direct Create Studio

Upload audio, create visuals, and create prompts to turn into videos.

A Vite + React single-page app: timeline scene slicing, a shot-deck scene designer with free AI keyframe stills (Pollinations Flux), a visual continuity engine with AI character portraits, a master assembly preview, and an MP4 export workflow.

## Run it locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The static site in `dist/` is deployed to GitHub Pages via the `gh-pages` branch.
